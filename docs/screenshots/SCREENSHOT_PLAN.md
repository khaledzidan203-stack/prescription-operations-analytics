# Synthetic Screenshot Plan

All screenshots in the public portfolio must be generated from synthetic data and neutral branding.

## Allowed Views

1. Executive Overview
2. Workflow Alpha Analysis
3. Workflow Beta Analysis
4. Workflow Gamma Analysis
5. Exceptions & Data Quality
6. Resource Requirements
7. Transfer & Lineage Analysis
8. Site Performance

## Required Safety Rules

- No real company logo or brand.
- No real branch/site codes.
- No real customer, employee, patient, transaction, or identifier data.
- No private terminology or internal acronyms.
- No reverse mapping between fictional and private labels.
- No real thresholds or timing windows.
- No production screenshots or cropped production interfaces.
- No infrastructure details, URLs, hostnames, or file paths.

## Visual Guidance

Use neutral titles, fictional site names, synthetic dates, and generic workflow labels. Screenshots should demonstrate dashboard design and analytical reasoning, not reproduce a private application's interface or operating process.
