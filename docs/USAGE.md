# Usage

## Streamlit
Use sidebar filters to change city, branch, and channel context. Review KPI cards, trends, channel results, shortage requirements, and detail rows.

## Power BI
Follow `powerbi/README.md`, build relationships from `powerbi/DATA_MODEL.md`, then add measures from `powerbi/MEASURES.md`.

## SQL
Run the analytical views and queries to reproduce KPI totals and shortage summaries.

## Portfolio review
A recruiter can start with `README.md`, inspect `PORTFOLIO_NOTES.md`, open the screenshots, then review calculation code in `src/analytics.py`, SQL in `sql/`, and BI definitions in `powerbi/`.
